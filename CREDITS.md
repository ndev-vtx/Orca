### Core open technologies Orca is built on

- **FastAPI** — async Python web framework powering the Orca API.
- **yt-dlp** — stream resolution and YouTube extraction fallbacks.
- **ytmusicapi** — YouTube Music catalog discovery (search, albums, charts, radio).
- **LRCLIB** — free, community-driven time-synced lyrics.
- **SQLite** — lightweight local storage for users, playlists and history.
- **React 18 + TypeScript + Vite 5** — the strict, fast frontend toolchain.
- **zustand** — minimal state management for the player engine.
- **Capacitor 7** — packaging the web app as a native Android APK.
- **Electron + electron-builder** — the Windows desktop wrapper.

Thank you to the maintainers and communities behind these projects.
